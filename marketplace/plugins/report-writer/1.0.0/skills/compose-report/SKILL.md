# Compose report

You receive a commentary document (JSON with title, highlights, risks, narrative) and optionally one supporting table (JSON array).

Produce a report with:
- A `# Title` heading taken from the commentary title.
- `## Summary`: the narrative paragraph.
- `## Highlights`: the highlights as a bullet list.
- `## Risks`: the risks as a bullet list.
- `## Supporting data`: if a table is provided, render up to 15 rows as a Markdown table with its original column names.
- A final line: `_Generated by the recipe engine POC._`

Return `title` and the full `markdown` string. Do not add facts that are not in the inputs.
